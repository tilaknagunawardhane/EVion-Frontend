# EVION - Electric Vehicle Mobile Application 🚗⚡

EVION is a mobile application designed for electric vehicle (EV) owners and power station owners to easily find charging stations, make bookings, plan trips, and manage their EV experiences efficiently.

## 📱 Features

* 🔍 **Locate Charging Stations**
  Search and view nearby EV charging stations using Google Maps integration.

* 📅 **Booking System**
  Reserve charging slots at preferred power stations in real-time.

* 💳 **Payment Integration**
  Seamless payment options for charging services.

* 🗺️ **Trip Planner**
  Plan trips with optimal charging stops along the route.

* ✅ **Booking History**
  View completed and upcoming bookings with detailed information.

* ⚙️ **Admin Dashboard (Web)**
  Manage stations, monitor bookings, and oversee system operations.

## 🚀 Tech Stack

* **Frontend:** React Native (Expo)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT, Google OAuth
* **Maps:** Google Maps API
* **Push Notifications:** Expo Notifications

## 🛠️ Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/tilaknagunawardhane/EVION-Frontend.git
   ```

2. Navigate to the project folder:

   ```bash
   cd EVION-Frontend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the project:

   ```bash
   expo start
   ```
